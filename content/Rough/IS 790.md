Independence 
Events A and B are independent if P(A,B) = P(A)P(B) or P(A|B) = P(A) or P(B|A) = P(B)
Events A and B are conditionally independent given X if 
P(A|B,C) = P(A|C)
P(B|A,C) = P(B|C)
P(A,B|C) = P(A|C)P(B|C)

If X is continuous then the probability distribution is called the density function f.
$\int_{a}^{b} f(x) \,dx$ and $\int_{-\infty}^{\infty} f(x)dx=1$

Marginalization is the calculation of probability using law of the total probability. It is called marginal probability.

**Potential Outcomes**
- Treatment, T (input) Any changes we make or action we perform
	When initiated then only it is treatment, it can later become an observation.
- Outcome, Y
	 If you take the medication 
Causal effect: $Y_i(1) - Y_i(0)$
Individual treatment effect (ITE)
$Y_i(1)$ Potential outcome under treatment
$Y_i(0)$ Potential outcome under no treatment

**Fundamental Problem of Causal Inference**
Not possible to compute the counterfactual data. And only factual data cannot express the causaily.
It is impossible to observe the causal effect on a single unit.
	We do not observe both potential outcomes.
We only observe either $Y_i(1)$ or $Y_i(0)$
This is a missing data problem --> missing counterfactuals, need to make assumptions.
